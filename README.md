# 📝 Blogging System

A full-stack blogging platform built using the **MERN Stack** that allows users to create, read, update, and delete blog posts. The application also provides authentication, comments, likes, and an admin dashboard for managing the platform.

## 🚀 Features

### 👤 User Features
- User Registration & Login
- Secure Authentication
- User Profile
- Create Blog Posts
- Edit Own Blog Posts
- Delete Own Blog Posts
- View All Blogs
- View Individual Blog Details
- Like / Unlike Blogs
- Add Comments
- View Comments

### 🛡️ Admin Features
- Admin Login
- Admin Dashboard
- Manage Users
- Manage Blog Posts
- Manage Comments
- View platform statistics

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- JavaScript
- React Router
- Axios
- Lucide React

### Backend
- Node.js
- Express.js
- REST API
- JWT Authentication
- Middleware

### Database
- MySQL
- Sequelize ORM
